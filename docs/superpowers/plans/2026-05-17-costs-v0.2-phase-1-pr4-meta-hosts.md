## Multi-host pricing decision

Meta releases the weights; pricing varies by host. Convention for these rows:

- **Capture the LOWEST published per-Mtok rate among the rows' `deployment_options[]` hosts.** This is the "best available" rate for cost-conscious agents.
- **Document the host responsible for the lowest rate in `notes`.** Include the spread: "Together $X / Fireworks $Y / Groq $Z / Bedrock $W; lowest from <host>."
- **If two hosts tie at the lowest rate**, pick the one with the more-stable URL (Together typically) and note the tie.
- **If a host doesn't publish a public price** (Bedrock often has reserved-capacity-only models for Llama 4), skip it from the price spread but still include in `deployment_options[]` if it hosts the model. Note the gap.
- **Don't set `confidence: medium` purely because there's a spread** — that's expected for multi-host models. Only flag medium if the spread is >2× or if hosts disagree on capability claims (context window, vision, etc.).

For `cache_read_per_mtok_usd`, `cache_write_per_mtok_usd`, `batch_input/output`: leave UNSET unless ALL `deployment_options[]` hosts publish the same caching/batch behavior. Together, Fireworks, and Groq generally do NOT publish prompt-caching prices for Llama. Bedrock has batch inference at a 50% discount for some models.

For `pricing_tiers[]`: leave UNSET — Llama hosts don't use long-context tiering.

### Fields to populate

For every Meta row:

- `model_family`: `"Llama 4"` for 4.x; `"Llama 3.3"` for 3.3

- `pricing_tiers[]`: UNSET

- `last_verified: "2026-05-18"`

- `verification_method: "manual-confirmed"`, `verified_by: "r13i"`
- `source_url`: point at the canonical Meta model card (`https://www.llama.com/models/...` or HuggingFace page), NOT a single host's pricing page

### Step 6: jq referential checks

```bash
for f in costs/llm.json costs/stt.json costs/tts.json; do
  dupes=$(jq -r '[.models[] | .aliases // [] | .[]] | group_by(.) | map(select(length > 1) | .[0])' "$f")
  unresolved=$(jq -r '(.models | map(.model_id)) as $ids | [.models[] | select(.replaced_by_model_id != null) | select((.replaced_by_model_id as $r | $ids | index($r)) == null) | .model_id]' "$f")
  echo "$f aliases: $dupes ; replaced_by: $unresolved"
done
```

Each line ends `[] ; replaced_by: []`. The aliases check is especially important here because PR4 introduces many alias strings and uniqueness across the entire file is enforced.
