## Critical: deprecation check first

PR5 and PR6 taught us subagents miss deprecation status. Verify before drafting:

- Check `https://docs.cohere.com/docs/models` and `https://cohere.com/pricing` for deprecation banners
- Command A (released 2025-03) is newer than Command R / R+; Command R / R+ may now be deprecated in favor of Command A

If any model is deprecated, set `deprecated_at` and `replaced_by_model_id` (to `command-a` if it's the in-file successor).

## Scope

3 new rows. Verify canonical model_ids against `https://docs.cohere.com/docs/models`:

1. `command-r-plus` (or `command-r-plus-08-2024` dated form)
2. `command-r` (or `command-r-08-2024` dated form)
3. `command-a` (or `command-a-03-2025` dated form)

If both dated and undated forms exist, use the dated form for `model_id` and put the undated in `aliases[]`.

## Per-row guidance

For each row:

- `provider: "Cohere"`, `provider_url: "https://cohere.com"`
- `model_id` (canonical Cohere API ID)
- `display_name` (e.g. "Command R+", "Command R", "Command A")
- `model_family` (e.g. "Command R", "Command A")
- `knowledge_cutoff` (verify in Cohere docs)
- `aliases[]` — undated `-latest` form if used dated for model_id; Bedrock model ID (`cohere.command-*-vN:0` style); Azure / Sagemaker IDs where published
- `context_window`, `max_output_tokens` from Cohere docs
- `input_per_mtok_usd`, `output_per_mtok_usd` from `https://cohere.com/pricing` (decimal strings)
- `cache_*` and `batch_*`: Cohere doesn't historically publish prompt-caching or batch discounts; verify and leave UNSET unless they have introduced them
- `pricing_tiers[]`: UNSET
- `modalities`: typically text-only for Command models. Verify Command A specifically (it may support vision).
- `supports_tool_use: true`, `structured_output: true` (Cohere RAG and tool-use APIs)
- `supports_vision`: verify per model
- `supports_audio_in: false`, `supports_audio_out: false`
- `supports_pdf`: verify (typically false at the model level; Cohere has separate document understanding via Embed)
- `reasoning_tokens_billed: false`
- `deployment_options[]`: at least `["native"]`. Add `bedrock`, `azure` where Cohere has published availability.
- `confidence: high` default
- `last_verified: "2026-05-18"`, `last_changed_at` (actual or today)
- `verification_method: "manual-confirmed"`, `verified_by: "r13i"`
- `source_url`: `https://cohere.com/pricing` or `https://docs.cohere.com/docs/command-*`
