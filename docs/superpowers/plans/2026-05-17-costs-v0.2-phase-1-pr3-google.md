### Task 1: Research and draft the Google Gemini rows

**Files:**

- Modify: `costs/llm.json`

**Working directory:** `/Users/r/playground/hail`

**Scope:**

- New rows: `gemini-2.5-flash`, `gemini-2.5-flash-lite`, `gemini-2.0-flash`. Verify the canonical Gemini API model IDs against `https://ai.google.dev/gemini-api/docs/models`. Append after the most recently added row.
- Backfill: `gemini-2.5-pro` with optional v2 fields.

**Google-specific guidance:**

- **Pricing tiers**: Gemini 2.5 Pro already has a `pricing_tiers[]` entry for the >200k-token tier from Phase 0. Verify whether 2.5 Flash and 2.5 Flash-Lite have the same long-context split — if so, populate `pricing_tiers[]` on those rows too.
- **Caching**: Google publishes "context caching" prices. Map to `cache_read_per_mtok_usd`. For Gemini, the API distinguishes implicit caching (always-on) from explicit caching (developer-managed). Capture the implicit (cache hit) rate as `cache_read_per_mtok_usd`. Cache write (explicit caching) bills per Mtok of cached content per hour — schema models this poorly, but if Google publishes a per-Mtok-stored rate, set `cache_write_per_mtok_usd`. Otherwise document the hourly storage rate in `notes` and leave `cache_write_per_mtok_usd` unset.
- **Batch API**: Gemini has a Batch Mode at 50% of base for synchronous models. Verify per model — Google has not historically offered batch on all Gemini variants.
- **Reasoning**: Gemini 2.5 Pro and 2.5 Flash have "thinking" budgets. When thinking is enabled, output tokens are billed at the same output rate (no separate reasoning-token rate). Set `reasoning_tokens_billed: true` for 2.5 Pro and 2.5 Flash; `false` for 2.5 Flash-Lite (no thinking) and 2.0 Flash (no thinking).
- **Multimodal**: All Gemini 2.x models accept text+image+audio+video input by default. `supports_vision: true`, `supports_audio_in: true`, `supports_audio_out: false` (Gemini doesn't generate audio natively; that's a separate Live API). `supports_pdf: true` — Gemini supports PDF via the file API.
- **Hosting**: Google Gemini is available via Google AI Studio (the native API) and Google Cloud Vertex AI. `deployment_options: ["native", "vertex"]`. Vertex's publisher model name is `<model_id>` — skip alias if duplicate (per PR1 convention).
- **Free tier**: Google AI Studio has a documented free tier (rate-limited). If you can express the limits as `requests_per_day` and/or `tokens_per_day`, populate `free_tier`. If the limit is per-minute rather than per-day, leave unset and document in notes.

**Fields to populate (in addition to v2 required fields):**

Each new row + backfill:

- `cache_read_per_mtok_usd`
- `cache_write_per_mtok_usd` (only if Google publishes a per-Mtok-stored rate, not hourly)
- `batch_input_per_mtok_usd`, `batch_output_per_mtok_usd` (only if Google offers batch for that variant)
- `pricing_tiers[]` (for long-context price changes — typically >200k tokens)
- `knowledge_cutoff` (YYYY-MM-DD, from Google's model card)
- `supports_tool_use: true`, `structured_output: true`
- `supports_vision: true`, `supports_audio_in: true`, `supports_audio_out: false`, `supports_pdf: true`
- `reasoning_tokens_billed`: `true` for 2.5 Pro and 2.5 Flash; `false` for 2.5 Flash-Lite and 2.0 Flash
- `deployment_options: ["native", "vertex"]`
- `aliases[]`: only if a hosted variant ID differs from the canonical (typically empty for Gemini)
- `free_tier`: populated if Google's free-tier limits map to per-day; else unset
- `last_verified: "2026-05-18"`
- `last_changed_at`: actual published last-changed date if available, else `"2026-05-18"`
- `verification_method: "manual-confirmed"`, `verified_by: "r13i"`

Backfill-specific (`gemini-2.5-pro`):

- Bump `last_verified` to `"2026-05-18"`. Do NOT change `last_changed_at`.
- Do NOT change any required field values.
- Existing row already has `pricing_tiers[]` — leave intact unless Google has updated the threshold or rates.
- The existing notes mention "Input pricing shown is for prompts <=200k tokens; prompts >200k tokens are billed per pricing_tiers" — keep this style intact.

**Leave UNSET:**

- `latency_benchmark` (Phase 1 deferral)
- Optional fields where Google's docs are silent — prefer absent over guessing
