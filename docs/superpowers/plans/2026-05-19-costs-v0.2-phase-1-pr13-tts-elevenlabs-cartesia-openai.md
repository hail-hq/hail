## Per-row data (TTS schema)

From the v2 TTS schema:

Required: `provider`, `provider_url`, `model_id`, `display_name`, `price_per_1m_chars_usd`, `voice_quality`, `languages`, `last_verified`, `last_changed_at`, `verification_method`, `verified_by`, `source_url`.

Optional (set when published):

- `voice_count`, `voices_count`, `voices_premium_count` (integers)
- `ssml_supported`, `emotion_control_supported`, `streaming_supported` (booleans)
- `voice_cloning`: bool OR `{price_usd, unit, min_seconds?}` object
- `output_formats[]` (strings)
- `sample_rates_hz[]` (integer array)
- `time_to_first_byte_ms` (integer)
- `min_billed_chars` (integer)
- `aliases[]`, `deployment_options[]`, `free_tier`, `deprecated_at`, `replaced_by_model_id`, `confidence`
- `notes`

`deployment_options` enum (now includes `"openrouter"` since v2.1): `["native", "bedrock", "vertex", "azure", "together", "fireworks", "groq", "replicate", "dashscope", "openrouter"]`.

## Field order (TTS)

Adapted from LLM/STT convention:

```
provider, provider_url, model_id, display_name,
aliases (when present),
price_per_1m_chars_usd, min_billed_chars (when set),
voice_quality, voice_count, voices_count, voices_premium_count (when set),
languages,
ssml_supported, emotion_control_supported, streaming_supported (when set),
voice_cloning (when set),
output_formats (when set), sample_rates_hz (when set),
time_to_first_byte_ms (when set),
deployment_options,
free_tier (when set),
deprecated_at, replaced_by_model_id (when present),
confidence (when non-default),
last_verified, last_changed_at, verification_method, verified_by,
source_url, notes
```

## Per-row defaults

- `confidence: high` default (omit field)
- `last_verified: "2026-05-19"`
- `last_changed_at`: actual published last-changed if available, else `"2026-05-19"`
- `verification_method: "manual-confirmed"`, `verified_by: "r13i"`
