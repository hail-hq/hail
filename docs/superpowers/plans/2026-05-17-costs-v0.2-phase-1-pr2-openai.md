**Fields to populate per row (in addition to v2 required fields):**

For every OpenAI row:

- `cache_read_per_mtok_usd` — OpenAI prompt-caching cached input rate (typically 0.5× input, but verify per model)
- `batch_input_per_mtok_usd`, `batch_output_per_mtok_usd` — Batch API, 50% of base
- `cache_write_per_mtok_usd` — OpenAI does NOT charge separately for cache write (unlike Anthropic). Leave UNSET unless OpenAI has changed this. Verify against the live pricing page.
- `knowledge_cutoff` (YYYY-MM-DD) — OpenAI publishes per model
- `supports_tool_use: true` for all current chat-completion models
- `structured_output: true` for models that support OpenAI structured outputs (GPT-4o, GPT-4.1, GPT-5 family, o-series 2024+)
- `supports_vision` — `true` for GPT-4o, GPT-4o mini, GPT-4.1, GPT-5 family, o1, o3 (verify each)
- `supports_audio_in`, `supports_audio_out` — `true` for GPT-4o and GPT-4o mini (omni models). Others are typically `false`. Verify.
- `supports_pdf` — verify. Some OpenAI models accept PDF via the Files API; record only if OpenAI documents native PDF support.
- `reasoning_tokens_billed: true` for o-series (o1, o3, o4-mini). For GPT-5 family, verify — OpenAI may bill reasoning tokens when reasoning mode is enabled.
- `aliases[]` — Azure OpenAI deployment name(s) where published. Format varies; Azure tends to use the same model name (e.g. `gpt-4o`), so often the alias equals the model_id. Skip an alias if it would duplicate the model_id (matches Anthropic precedent in PR1).
- `deployment_options[]` — at least `["native", "azure"]` for all current OpenAI models. Add `bedrock` only if AWS Bedrock hosts the model.
- `confidence: high` is default; `medium` only with documented reason.
- `last_verified: "2026-05-17"`
- `last_changed_at` — actual last-changed date if OpenAI publishes one in a price footnote; otherwise `"2026-05-17"`.
- `verification_method: "manual-confirmed"`, `verified_by: "r13i"`

For deprecated rows (verify which models are deprecated against `https://platform.openai.com/docs/deprecations`):

- `deprecated_at` — deprecation announcement or sunset date
- `replaced_by_model_id` — must resolve to a `model_id` in the same file after this PR

**Leave UNSET for Phase 1 PR2:**

- `pricing_tiers[]` — OpenAI may have usage tiers; if so, populate. Otherwise leave unset.
- `free_tier` — only set if OpenAI has documented a free API tier (they typically don't).
- `latency_benchmark` — deferred.
