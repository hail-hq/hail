## Per-row data (STT schema)

For every new row:

- `provider` — `"Deepgram"` or `"AssemblyAI"`
- `provider_url` — `"https://deepgram.com"` or `"https://www.assemblyai.com"`
- `model_id` — canonical API model_id (verify against docs)
- `display_name` — readable name (e.g. "Nova-3 Medical", "Universal-1")
- `price_per_minute_usd` — required decimal string from vendor pricing
- `price_per_minute_batch_usd` — optional batch/async rate if vendor publishes a discount
- `diarization_per_minute_usd` — optional, capture if vendor publishes (Deepgram does for some models)
- `pii_redaction_per_minute_usd` — optional, capture if vendor publishes
- `languages` — required, array of language codes or `"N+"` string format
- `streaming` — required bool
- `realtime` — optional bool
- `realtime_latency_ms` — optional integer
- `diarization` — optional enum: `"included"` / `"extra-cost"` / `"unsupported"`. Use `"extra-cost"` if `diarization_per_minute_usd` is set; `"included"` if free; `"unsupported"` if not offered.
- `punctuation_included` — optional bool
- `formatting_included` — optional bool
- `min_billed_seconds` — optional integer (e.g. Groq STT bills 10s minimum)
- `max_audio_minutes_per_file` — optional integer
- `concurrent_streams_included` — optional integer
- `wer_benchmark` — optional object with vendor-published WER score
- `time_to_first_word_ms` — optional integer
- `aliases[]` — alternative model_ids (rare for STT)
- `deployment_options[]` — at minimum `["native"]`. Add `"bedrock"`, `"azure"`, `"vertex"` etc. only if verified.
- `free_tier` — optional `{requests_per_day?, tokens_per_day?}` object
- `deprecated_at` + `replaced_by_model_id` if deprecated (must resolve in-file post-PR)
- `confidence: high` default (omit field)
- `last_verified: "2026-05-19"`
- `last_changed_at` — actual published last-changed if available, else `"2026-05-19"`
- `verification_method: "manual-confirmed"`, `verified_by: "r13i"`
- `source_url` — vendor pricing page
- `notes` — 1-3 sentences

## Field order (STT)

Same shape as LLM convention adapted to STT fields:

```
provider, provider_url, model_id, display_name,
aliases (when present),
price_per_minute_usd,

languages, streaming, realtime, realtime_latency_ms (when set),
diarization, punctuation_included, formatting_included (only when set),
min_billed_seconds, max_audio_minutes_per_file, concurrent_streams_included (only when set),
wer_benchmark (when set), time_to_first_word_ms (when set),
deployment_options,
free_tier (when set),
deprecated_at, replaced_by_model_id (when present),
confidence (when non-default),
last_verified, last_changed_at, verification_method, verified_by,
source_url, notes
```

## Steps (cap ~4 WebFetch calls)

1. Read schema enum for `deployment_options` (same enum as LLM): `cat costs/schema/stt.schema.json | jq '.["$defs"].model.properties.deployment_options'`

2. Read current state: `cat costs/stt.json | jq '.models[] | select(.provider == "Deepgram" or .provider == "AssemblyAI")'`

3. WebFetch `https://deepgram.com/pricing` — verify Nova-3 Medical / Finance pricing and model_ids.

4. WebFetch `https://www.assemblyai.com/pricing` — verify Universal-1 and Slam-1 pricing and deprecation status.

5. Optional WebFetch each vendor's models docs page only if the pricing page is thin.

6. Use the `Edit` tool to append 2-4 rows to `costs/stt.json`. Match field order. Decimal-string prices.

7. Run `pnpm costs:validate` — must pass all three.

8. Run jq referential checks (same as LLM PRs).

9. Run `pnpm site:build` — must pass.

10. `git add costs/stt.json`. Confirm `M  costs/stt.json` staged.
