## Scope (~5 rows, flexible)

### Alibaba Qwen 3 (2-3 rows)

Choose the top of the family. Likely candidates:

- `qwen3-max` or `qwen3-235b-a22b-instruct` (largest MoE)
- `qwen3-coder` (code-specialized)
- Optionally a mid-size variant like `qwen3-32b` if it's a meaningful tier

### Perplexity Sonar (2-3 rows)

Likely candidates:

- `sonar` (base model with web search)
- `sonar-pro` (higher-quality, with web search)
- Optionally `sonar-reasoning` or `sonar-reasoning-pro`

If a model is reasoning-capable, set `reasoning_tokens_billed: true`.

## Per-row guidance

### Qwen rows

- `provider: "Alibaba"`, `provider_url: "https://www.alibabacloud.com/product/modelstudio"` (or `https://qwenlm.github.io` if more canonical)
- `aliases[]`: include OpenRouter slug if Qwen 3 is hosted there with a stable name; Together / Fireworks IDs where Mistral-style multi-host pattern applies (BUT: Qwen 3 is operated by Alibaba on DashScope, not just open-weight, so DashScope is canonical even when hosted elsewhere)
- `deployment_options[]`: at least `["dashscope"]`. Add `together`, `fireworks`, `groq` only if verified.
- `cache_read_per_mtok_usd`: DashScope has documented prompt-caching for some Qwen models — verify
- `pricing_tiers[]`: DashScope tiers Qwen pricing by context-window bracket (similar to Gemini's long-context tier) — capture if published
- `modalities`: Qwen 3 is text-only in most variants; verify per row
- `supports_tool_use`, `structured_output`: typically `true` for current Qwen — verify
- `supports_vision`: `false` for text-only Qwen 3 (there's a separate Qwen3-VL family, not in scope)
- `reasoning_tokens_billed`: Qwen 3 has "thinking" mode — verify whether DashScope bills it separately

### Perplexity Sonar rows

- `provider: "Perplexity"`, `provider_url: "https://www.perplexity.ai"`
- Sonar pricing is unusual: many models charge per-request OR per-token + per-search. Capture per-token rates in the structured fields; document per-request and per-search add-ons in `notes`.
- `deployment_options: ["native"]` only — Perplexity isn't on Bedrock/Vertex/Azure
- `cache_*`, `batch_*`, `pricing_tiers`: typically UNSET for Perplexity
- `modalities`: text-only typically
- `supports_tool_use`: Perplexity's API treats web search as built-in, not a tool. Be careful here — set based on whether `tools` param is supported.
- `reasoning_tokens_billed`: `true` for `sonar-reasoning*` variants; `false` for base `sonar`
- `notes`: mention web-search-by-default, per-request and per-search fees if applicable
