### Pricing convention

Unlike the Llama PR4, Mistral models are operated by Mistral itself. La Plateforme prices are canonical:

- Set `input_per_mtok_usd` / `output_per_mtok_usd` from Mistral's published pricing page
- `deployment_options[]` enumerates where else the model is hosted (Bedrock, Vertex, Azure, Together if applicable)
- Don't try to track per-host prices in the structured fields — Mistral's price is the canonical

### Fields per row

For every Mistral row:

- `provider: "Mistral"`, `provider_url: "https://mistral.ai"`
- `model_id` — canonical Mistral API model ID
- `display_name` — e.g. "Mistral Large 2"
- `model_family` — e.g. "Mistral Large", "Codestral", "Pixtral"
- `knowledge_cutoff` from model card
- `aliases[]` — include Bedrock / Vertex / Azure model IDs where Mistral is hosted; include the `-latest` alias if you used the dated form as `model_id`
- `context_window`, `max_output_tokens` from model card
- `input_per_mtok_usd`, `output_per_mtok_usd` from La Plateforme pricing (decimal strings)
- `batch_input_per_mtok_usd`, `batch_output_per_mtok_usd` — Mistral's Batch API at 50% discount (verify availability per model)
- `cache_read_per_mtok_usd`, `cache_write_per_mtok_usd` — UNSET unless Mistral has published prompt-caching prices (they may not)
- `modalities`:
  - Pixtral: `{input: ["text", "image"], output: ["text"]}`
  - Others: `{input: ["text"], output: ["text"]}`
- `supports_tool_use`, `structured_output` — typically `true` for current Mistral chat models; verify Codestral (code-focused, may differ)
- `supports_vision`: `true` only for Pixtral
- `supports_audio_in: false`, `supports_audio_out: false`
- `supports_pdf`: verify per model (typically `false` at API level)
- `reasoning_tokens_billed: false` (Mistral doesn't have reasoning-token billing as of last check; verify)
- `deployment_options[]` — at least `["native"]`. Add `bedrock`, `vertex`, `azure` where Mistral has published availability.
- `free_tier`: La Plateforme has a free "Experiment" tier with documented rate limits — populate if it maps to `requests_per_day` or `tokens_per_day`; otherwise leave unset and document in notes.
- `confidence: high` default
- `last_verified: "2026-05-18"`, `last_changed_at`: actual published last-changed if any, else `"2026-05-18"`
- `verification_method: "manual-confirmed"`, `verified_by: "r13i"`
- `source_url`: Mistral's pricing page (`https://mistral.ai/pricing`) or model card
- `notes`: 1-3 sentences with anything notable (Codestral being code-specialized; Pixtral's vision support; tool use caveats for non-chat models)
