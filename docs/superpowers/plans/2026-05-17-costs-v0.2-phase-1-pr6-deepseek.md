### Fields per row

For every DeepSeek row (new + backfill):

- `provider: "DeepSeek"`, `provider_url: "https://www.deepseek.com"`
- `model_id` per canonical DeepSeek API ID
- `display_name` (e.g. "DeepSeek V3", "DeepSeek R1")
- `model_family` (e.g. "DeepSeek V3", "DeepSeek R1")
- `knowledge_cutoff` from DeepSeek docs
- `aliases[]` — historical names that route to this model (e.g. `deepseek-chat` for V3 if that's the API alias)
- `context_window`, `max_output_tokens` from DeepSeek docs
- `input_per_mtok_usd`, `output_per_mtok_usd` from DeepSeek's published pricing (decimal strings)
- `cache_read_per_mtok_usd` — DeepSeek publishes cache hit rates (typically 1/50th or similar of input)
- `cache_write_per_mtok_usd`, `batch_*` — only if DeepSeek publishes them; otherwise UNSET
- `pricing_tiers[]` — UNSET unless DeepSeek tiers
- `modalities`: text-only typically; verify R1 (typically text)
- `supports_tool_use: true`, `structured_output: true` for chat models; R1 may have caveats — verify
- `supports_vision: false` (DeepSeek API models are text-only typically; verify)
- `supports_audio_in: false`, `supports_audio_out: false`, `supports_pdf: false`
- `reasoning_tokens_billed: true` for R1; `false` for V3
- `deployment_options[]`: at least `["native"]`. Add Together/Fireworks/Groq/Bedrock only if verified
- `confidence: high` default
- `last_verified: "2026-05-18"`, `last_changed_at` (actual published date if different, else `"2026-05-18"`)
- `verification_method: "manual-confirmed"`, `verified_by: "r13i"`
- `source_url`: `https://api-docs.deepseek.com/quick_start/pricing`
- `notes`: 1-3 sentences with anything notable (cache discount, R1's reasoning behavior, deprecation status, etc.)
