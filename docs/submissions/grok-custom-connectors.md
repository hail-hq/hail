# Grok custom connectors (xAI)

Grok has no public connector directory to submit to. Each user adds a custom connector by URL.

## Steps to submit

None. A user adds Hail like this. The steps come from Manufact's summary (2026-11-04) of <https://docs.x.ai/grok/connectors>, not from the xAI page itself:

1. Open <https://grok.com/connectors>.
2. Choose **New Connector**, then **Custom**.
3. Enter `https://mcp.hail.so`.

Grok Business and Enterprise: a team admin adds the connector in the xAI cloud console.
