Hail v1 wraps three external services. Provision each, drop credentials into `.env`, and `docker compose up` does the rest.

## Order

1. **[LiveKit Cloud](/setup/livekit)** — media (SIP bridge + WebRTC). Required before voicebot can join calls.
2. **[Twilio](/setup/twilio)** — phone numbers + SIP trunk. The Origination URI from LiveKit goes into the Twilio trunk config.
3. **[MCP clients](/setup/mcp)** — connect Claude.ai / ChatGPT / Cursor / Claude Code to your Hail deployment. Independent of voice setup; needed only for agent-driven flows.

For one-click client setup snippets, also see the [client picker on hail.so/mcp](https://hail.so/mcp).
