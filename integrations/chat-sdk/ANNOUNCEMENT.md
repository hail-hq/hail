Hail now connects SMS to Vercel Chat SDK.

Install `@hail-hq/chat-sdk-adapter` and give your bot a Hail phone number. Receive signed SMS webhooks and reply from the same number using `thread.post()`.

The adapter supports rotating credentials, phone-pair conversation isolation, and Chat SDK state-backed history.

Get started: https://hail.so/docs/webhooks#chat-sdk

Source: https://github.com/hail-hq/hail/tree/main/integrations/chat-sdk

Hail maintains the adapter. A Vercel vendor-official listing is a separate submission and is not yet approved.
